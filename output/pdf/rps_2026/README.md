# RPS 2026 submission bundle

The submission source is `main.tex`. The verified submission PDF is
`rps_2026_unsupervised_lartpc.pdf`. The source uses the supplied NeurIPS 2026 style in
double-blind workshop mode and sets the workshop title to Representations for
the Physical Sciences Workshop.

Compile with:

```sh
latexmk -pdf main.tex
```

This command produces `main.pdf`; rename it to the submission filename above
after recompiling.

The scientific content occupies four pages and ends before the references.
References and technical appendices follow.
